## How To Prepare

1. Learn the 2-minute project explanation first.
2. Practice the order flow without looking at notes.
3. Be ready to explain why Kafka, MongoDB, Redis, Keycloak, React Query, and outbox were used.
4. Practice one failure story: inventory failure, payment failure, DLQ, or duplicate order.
5. Tie every technology answer back to a real EventCart file, API, or behavior.

The strongest interview answers are not only definitions. They connect a concept to a design choice, a trade-off, and a real debugging step.
