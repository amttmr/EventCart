# Technology Deep Dives

These documents explain the main technologies used in EventCart from a developer and interview-preparation point of view.

Each document follows the same pattern:

- Where the technology is used in EventCart.
- Why it was chosen.
- Best practices.
- How to verify behavior locally.
- How to debug and monitor it.
- Interview talking points and questions.

## Suggested Learning Order

1. Read MongoDB and Spring Data MongoDB together.
2. Read Apache Kafka and Spring Kafka together.
3. Read Redis after order-service idempotency.
4. Read Keycloak and Spring Security OAuth2 Resource Server together.
5. Read Observability after running a full order flow.
6. Read Kubernetes and GitHub Actions after the local application is working.
